Setup, R libraries and data download

Preparation instructions for the upcoming Wednesday tutorials

Hello everyone!

We’ll start with some data analyses in the upcoming Wednesday tutorials.

To be ready for that, please complete the preparation steps below.

1) Download Docker Desktop for the tutorial environment

You can install Docker Desktop from the following link on your laptop:
https://www.docker.com/products/docker-desktop/

After installation, start Docker on your laptop and use the recommended settings. You can either create a Docker account or skip the login step.

When Docker starts, search for the following image:

erkinacar5/sboc26

Press Pull to download the image. It is approximately 6–7 GB, so this may take a while.

After pulling is complete, press Run on the image and configure the following settings:

Ports

  • Host port: 8787

Volumes

  • Create a tutorial folder on your laptop
  • Host path: your tutorial folder
  • Container path: /tutorial

Environment variables

  • Variable: PASSWORD
  • Value: tutorial

Once these settings are configured, press Run to start the container.

Why do we use a container?

Due to the required libraries for this tutorial, it is difficult to ensure that everyone can install all necessary tools on their own computer.

We therefore use an isolated environment where everything is already installed and running. This also makes the tutorial more reproducible and avoids version conflicts.

You should be able to see the running container by clicking Containers in the left panel of Docker Desktop. Click the small browser/window icon under the Port(s) column to open RStudio in your browser.

Use the following login credentials:

Usernamerstudio Passwordtutorial

2) Download the input data

We will need the following data for the tutorials. Please download the files and place them in the tutorial folder you created, so that they are available inside RStudio later.

  1. Chromium FFPE Human Breast Cancer — filtered feature-barcode matrix
  2. CytAssist FFPE Human Breast Cancer — filtered feature-barcode matrix
  3. CytAssist FFPE Human Breast Cancer — spatial data archive

That’s it! See you at the tutorial.
